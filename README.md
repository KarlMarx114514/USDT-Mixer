# 零知识证明
零知识证明是一种密码学方法，允许一方在不泄露数据本身的情况下，向另一方证明自己掌握这个数据。

以混币器作例子的话，用户在从混币器中取款时，向混币器提交证明，以证明自己掌握某个特定的密钥（该密钥唯一对应先前的某笔特定的存款）。提交的证明里并不包含密钥本身，但却可以充分地验证提交证明的用户是否真的掌握该密钥，只要提交的证明通过验证，用户的取款就被批准。这样一来，即使全部流程都在链上公开进行，没有其他人（哪怕是混币器本身）能够知道哪一笔取款对应着哪一笔存款，从而实现混币。这里介绍一个可以介绍解释零知识证明基本思想的例子。

假设有一个山洞，只有一个入口，但内部有两条互相连通的路径（路径A和路径B），它们在一个带密码锁的门处汇合。山洞内的Alice想向Bob证明她知道密码锁的密码，但又不想让Bob知道密码是什么，因此她让Bob全程站在山洞外面。

为了做到这一点，Alice进入山洞并随机选择路径A或B走向门，然后Bob在山洞外随机要求她从路径A或B回到入口。这样如果Alice最初选择了路径A，而Bob要求她从路径B返回，那么Alice只有打开密码锁穿过门才能做到。但如果Alice运气好，恰巧最初就选择了路径B呢？没关系，Bob可以重复这个过程一万遍，十万遍，如果每次Alice都能按照Bob的要求返回入口，那么Bob就可以确信Alice不是运气好蒙对了，而是真的知道密码锁的密码是多少。同时，Bob整个过程都在山洞外，完全没有任何偷窥到密码的可能，这就是零知识证明的基本思想。在计算机科学中，这样的概念可以通过“电路”实现，即输入数据通过逻辑门的特定路径生成输出。零知识证明利用这些电路证明某个声明为真，而不会暴露输入数据本身。
